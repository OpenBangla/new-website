# নিয়ম ১: স্বরবর্ণ লেখা-

বাংলা মূল স্বরবর্ণ লেখার জন্য আপনি নিচের ইংরেজি বর্ণগুলো ব্যবহার করবেন:

| স্বরবর্ণ | ইংরেজি বর্ণ | | স্বরবর্ণ | ইংরেজি বর্ণ |
| :--- | :--- | :--- | :--- | :--- |
| অ | o | | ঋ | rri (all small) |
| আ | a | | এ | e |
| ই | i | | ঐ | OI (all capital) |
| ঈ | I (capital), ee | | ও | O (capital) |
| উ | u, oo | | ঔ | OU (all capital) |
| ঊ | U (capital) | | | |

<Callout type="info">
  <strong>লক্ষ করুন:</strong> ঈ,ঊ,ঐ, ও, ঔ স্বরবর্ণগুলো আপনাকে Capital/Block letter এ লিখতে হবে।
  ব্যাপারটি আপনি এভাবে সহজে মনে রাখতে পারেন- ই (i) থেকে ঈ (I) তে যেহেতু উচ্চারণে বেশি জোর দিতে হচ্ছে
  তাই এটা আপনাকে Capital/Block letter এ লিখতে হবে।
</Callout>

বাংলা স্বরবর্ণের সংক্ষিপ্ত রূপ (কার/মাত্রা) লেখার জন্যও মূল স্বরবর্ণের মত একই ইংরেজি বর্ণ করতে হবে-

| কার/মাত্রা | ইংরেজি বর্ণ | | কার/মাত্রা | ইংরেজি বর্ণ |
| :--- | :--- | :--- | :--- | :--- |
| া | a | | ৃ | rri (small) |
| ি | i | | ে | e |
| ী | I (capital), ee | | ৈ | OI (all capital) |
| ু | u, oo | | ো | O (capital) |
| ূ | U (capital) | | ৌ | OU (all capital) |

স্বরবর্ণ এবং স্বরবর্ণের সংক্ষিপ্ত রূপ (কার/মাত্রা) লিখতে একই ইংরেজি বর্ণ ব্যবহার করলেও অভ্র ফনেটিক বুঝতে পারবে কোন জায়গায় মূল স্বরবর্ণ এবং কোন জায়গায় এটার সংক্ষিপ্ত রূপ (কার/মাত্রা) ব্যবহৃত হবে।
